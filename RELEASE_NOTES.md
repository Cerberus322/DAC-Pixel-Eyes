# v0.1.2-test — English UI and Arctis Pro Wireless test mode

- English settings window, tray menu, notifications and validation messages.
- New **Arctis Pro Wireless (Test)** display-profile button.
- Experimental 128×48 output with matching `screened-128x48` binding, `image-data-128x48` event payload and 768-byte monochrome bitmap.
- Default 128×52 GameDAC output remains available.
- Live profile switching, with stored device preference and legacy smoothness-setting migration.
- Scrollable settings window for smaller displays.
- Existing clock hotkeys, random animations, startup preference and smoothing controls are retained.

**Hardware status:** the original wired Arctis Nova Pro / GameDAC setup was tested. The older Arctis Pro Wireless output is experimental and has only been verified at the software-payload level. Nova Pro Wireless compatibility is not confirmed.

Download `DACPixelEyes-v0.1.2-test-windows-x64.zip`, extract everything, and run `DACPixelEyes/DACPixelEyes.exe`. GG must remain open. Python is not required for this download.

Please include the exact device model and selected profile when reporting a problem. Check logs for personal paths before attaching them.
